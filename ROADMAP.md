# Roadmap

## v0.2 — Investigations and callout expansion

- Witness interview framework
- Evidence markers and basic scene notes
- Missing Hunter
- Body Discovered
- Livestock Theft
- Escaped Prisoner
- Strawberry, Annesburg and Tumbleweed duty stations
- More scenes per jurisdiction

## v0.3 — Deputy career

- Duty uniform and configurable badge
- Partner/backup requests
- Promotion notifications and rank rewards
- Performance ratings
- Live-or-dead objective modifiers
- Prisoner wagon support

## v0.4 — Living law system

- Regional crime trends
- Repeat offenders
- Wanted posters generated from unresolved calls
- Jail population/persistence hooks
- Compatibility API for other immersion mods

## v1.0 target

- Twelve or more polished callouts
- Multiple suspects and branching outcomes
- Evidence, witnesses, arrests and prisoner transport fully integrated
- Jurisdiction-specific dispatch pools
- Complete configuration documentation
- Full clean-save and compatibility test matrix
