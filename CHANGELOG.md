## Beta 0.1.0 — Initial playable foundation

- Added four configurable duty stations.
- Added automatic and manual dispatch systems.
- Added weighted callout selection and offer timeouts.
- Added Saloon Disturbance, Roadside Robbery and Wanted Outlaw callouts.
- Added surrender, fight and flee suspect outcomes.
- Added contextual cuffing plus vanilla hogtie detection.
- Added escort, prisoner transport and sheriff-office booking.
- Added JSON profile persistence, XP, ranks and statistics.
- Added optional callout pay.
- Added station/callout blips and optional duty HUD.
- Added editable INI and location JSON with safe hot reload.
- Added defensive entity cleanup and diagnostic logging.
